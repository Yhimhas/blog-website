## 1. 当前架构

- 前端：Vue 3 + TypeScript + Vite；公开页面使用构建时 HTML 快照，浏览器挂载后由 Vue 接管。没有迁移到 Nuxt SSR。
- 后端：Go + Gin + GORM + PostgreSQL；版本化 SQL 由管理命令显式迁移，当前迁移到 `000005_post_revisions`。
- 音乐：平台元数据适配器、每日推荐、匿名播放会话、媒体代理及按需 FFmpeg 转码。普通 API 与媒体使用不同监听端口。
- 接口与运行入口：[OpenAPI](../api/openapi.yaml)、[后端 README](../backend/README.md)、[前端 README](../frontend/README.md)。

### 当前行为中需要特别注意的部分

- 保存已发布文章的修订不会改变公开正文；发布修订后 API 更新，但搜索引擎和无 JavaScript 访问者看到的静态 HTML 仍需重新构建发布。
- 发布、更新或归档文章后都需要重新生成 SEO 快照。当前没有自动发布 hook；必须切换整个新输出目录，不能合并旧 HTML。仅归档数据库记录不能撤回旧静态副本或 CDN 缓存。
- 播放进度定位通过 `startSeconds` 创建新会话并由 FFmpeg 定位，不是浏览器直接使用 Range/206；可能需要重新准备音频。试听位置相对于试听片段，未知时长不启用定位。跨路由持续播放不等于刷新或关闭页面后继续播放。
- 同步元数据不代表曲目完整可播；unknown 不会仅因有效音频头或元数据时长变为 full。账号客户端已实现，真实账号权益、音源与轮换仍待实测。
- 本地 Markdown、本地草稿与数据库文章是不同数据源。本地示例文件不会自动导入数据库；账号登录也不代表已有跨设备收藏同步。
